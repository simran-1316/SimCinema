# SimCinema 🎬

SimCinema is a frontend movie streaming web application built using React. The project focuses on creating a modern and responsive user interface inspired by popular streaming platforms while improving frontend development skills and component-based architecture.

## 🚀 Features

- Responsive modern UI
- Movie/show cards section
- Dynamic React components
- Smooth navigation experience
- Clean homepage layout
- Interactive frontend design

## 🛠️ Tech Stack

- React
- JavaScript
- HTML
- CSS

## 📚 What I Learned

Through this project, I improved my understanding of:
- React fundamentals
- Component-based architecture
- State and props handling
- Responsive frontend development
- UI/UX design principles

## 🎯 Purpose

This project was built to practice React and frontend development by creating a modern movie streaming platform interface and improving real-world development skills.
